# URW Quest Trainer 0.25

For UnReal World 3.89.1 on Windows. Faster item delivery, corrected pickup confirmation and a quality filter for existing world variants (levels 1–5). Compatible with Player and Plus Hook 0.46.

Download **URW_QuestTrainer_0.25.zip** from [Releases](https://github.com/Librianets/UnRealWorld_QuestTrainer/releases/latest), extract into a separate folder and run **URW_QuestTrainer.exe**. Existing installations can use the trainer's update button.

The interface is Russian. See [Russian instructions](README_RU.md) for character, skill, condition, item, quest and animal tools and their limits. Changes affect the loaded character/world; use a test character or backup.

The normal archive retains the compact layout supported by previous updaters. The optional fullsource archive contains separate headers; both contain the same executable. Source builds use Visual Studio 2022, x86, build.cmd.
