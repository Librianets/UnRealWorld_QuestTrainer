# URW Quest Trainer 0.23

For UnReal World 3.89.1 on Windows. This release adds compatibility with the repaired Player Hook 0.45; existing trainer features remain available.

Download **URW_QuestTrainer_0.23.zip** from [Releases](https://github.com/Librianets/UnRealWorld_QuestTrainer/releases/latest), extract into a separate folder and run **URW_QuestTrainer.exe**. Existing installations can use the trainer's update button.

The interface is Russian. See [Russian instructions](README_RU.md) for character, skill, condition, item, quest and animal tools and their limits. Changes affect the loaded character/world; use a test character or backup.

The normal archive retains the compact layout supported by previous updaters. The optional fullsource archive contains separate headers; both contain the same executable. Source builds use Visual Studio 2022, x86, build.cmd.
