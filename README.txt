URW Quest Trainer 0.06 — UnReal World 3.89.1

Отдельный тренер для проверки перевода: создание предложений заданий у NPC
и добавление предметов в инвентарь. Запускается отдельно от перевода.
Используйте тестового персонажа: созданные вещи и задания остаются в его мире.

СОЗДАТЬ ПРЕДЛОЖЕНИЕ ЗАДАНИЯ
1. Загрузите живого персонажа и откройте локальную карту рядом с человеком.
   Закройте инвентарь, разговор и другие меню.
2. Откройте URW_QuestTrainer.exe. Игра найдётся автоматически.
   Если запущено несколько игр, выберите нужную в списке.
3. Выберите тип задания и нажмите «Создать задание».
   Для первой проверки выбран «72 — Сбор веток».
4. Дождитесь CHOOSE TARGET в самой игре. Только после этого укажите человека
   мышью или игровым курсором и подтвердите Enter. На вопросы Y/N ответит тренер.
   Во время автоматики не нажимайте другие клавиши и не переключайте окна.
5. Дождитесь сообщения с номером и названием созданного предложения.
6. Затем ПОГОВОРИТЕ с этим человеком и примите его просьбу обычным способом.
   Только принятое задание появится в F2. Само создание предложения не
   означает принятия задания вашим персонажем.

Доступны 16 типов. Сезон, нужный NPC, возраст персонажа и другие условия
проверяет игра. Минимальный игровой день тренер проверяет заранее: например,
похититель птиц (15) доступен с 10-го дня; для камней сауны нужна подходящая
баня в поселении. Сбор трав зимой может не создаться. Если игра
не создаст предложение, тренер сообщит об этом, не объявляя успех.
«Открыть штатное меню вручную» открывает выбор NPC; дальше отвечайте Y/N сами.

ДОВЕСТИ СТАЖ ДО 100 ДНЕЙ
1. Вернитесь на основной экран локальной карты и закройте меню.
2. Нажмите «Довести стаж до 100 дней». Тренер вызовет штатную служебную
   команду игры и пропустит недостающие дни: например, с 1-го до 100-го — 99.
3. Дождитесь подтверждения. Если уже прошло 100 или больше дней,
   повторное нажатие ничего не меняет и не возвращает время назад.
4. Теперь выбирайте нужный тип задания и создавайте предложение у NPC.
   Для появления задания в F2 поговорите с этим NPC и примите просьбу.

Функция предназначена для тестового персонажа: вместе со стажем меняются
календарь и общее игровое время. У старых заданий могут истечь сроки.
Сезонные требования, нужное поселение/NPC, баня и ограничения повторной выдачи
сохраняются. Кнопка не обещает создание любого задания в любом месте.

ДОБАВИТЬ ПРЕДМЕТ
1. Откройте основной экран локальной карты, закройте все меню.
2. Внизу тренера выберите предмет и количество 1–100.
   Показаны русская подпись и английское название. Одноимённые прототипы
   различаются ID; выбранный ID сохраняется при выдаче.
   Можно напечатать точное русское или английское название; регистр не важен.
   Если названию соответствует несколько ID, выберите нужную строку из списка.
   Список читается из прототипов текущей игры. После загрузки другого
   персонажа нажмите «Обновить предметы из игры».
3. Нажмите «Добавить предмет» и дождитесь подтверждения.
   Игра сначала создаёт предмет под ногами, затем тренер подбирает его
   штатным действием. Количество считается в игровых единицах:
   например 1 Nettle leaves — один пучок листьев крапивы.
4. Если предметы слишком тяжёлые, не видны на странице подбора или возникло
   другое окно, автоматика остановится. Уже созданные предметы могут
   остаться под ногами — их можно подобрать вручную клавишей g.
   Составные имена, качество и произвольные модификаторы этот список
   не конструирует: выдаётся выбранный базовый прототип.

ПРОВЕРИТЬ СВЕДЕНИЯ О ТРАВАХ
По умолчанию выбран Nettle leaves. Добавьте 1–3 пучка. На локальной карте
нажмите s и выберите HERBLORE / Травничество. Если рядом нет растений,
игра предложит изучить растительный предмет из инвентаря. Выберите листья.
Если рядом растут растения, сначала предлагается указать их на карте;
для проверки именно инвентаря перейдите на место без растений поблизости.

ОСТАНОВКА И СОВМЕСТИМОСТЬ
При потере фокуса, остановке, неизвестном окне или тайм-ауте дальнейший ввод
прекращается. Открытый диалог завершите вручную, вернитесь на основной экран
и повторите. Тренер не посылает дополнительные Escape наугад.
Не нажимайте повторно «Создать»/«Добавить» для продолжения оборванного диалога.
Тренер сам временно включает английскую раскладку и возвращает прежнюю.

ОБНОВЛЕНИЕ ТРЕНЕРА
Нажмите «Проверить обновления тренера». Нужны Интернет и Windows PowerShell 5.1, входящий в состав Windows 10/11.
PowerShell запускается только для обновления; во время игры он не работает.
Проверяется последний релиз только репозитория UnRealWorld_QuestTrainer:
https://github.com/Librianets/UnRealWorld_QuestTrainer/releases/latest
Если есть новая версия, подтвердите загрузку. Проверяются SHA256 архива и
каждого файла; тренер закроется, обновится и откроется снова. Игру закрывать
не требуется. Сохраняется одна предыдущая копия в URW_Trainer_backup.
Не удаляйте URW_TrainerUpdater.ps1 — он нужен кнопке обновления.
В случае ошибки остаётся сообщение, а незавершённая замена откатывается.
Можно также скачать ZIP вручную и распаковать с заменой при закрытом тренере.

ОГРАНИЧЕНИЯ ГЕНЕРАТОРА
Один человек может быть связан с действующей просьбой. Повторная выдача
того же типа проверяется самой игрой; например, для сбора веток действует
проверка предыдущего задания за 90 игровых дней. Отказ игры и остановка ввода
тренером — разные ситуации. Не удаляйте игровые QST для повторной проверки:
возьмите другого подходящего NPC/тип или отдельного тестового персонажа.

Поддерживается чистый EXE 3.89.1 с SHA256:
c6ed73642c1b1cb1f86b818c7586224398c2f0554f6114ced31bc40ff071806d
Поддерживаются английский запуск без хука и перевод с Hook 0.26/0.27/0.28,
в том числе через Steam. Неизвестная сборка DLL отклоняется до ввода команд.
Выбирается настоящее окно игры.
EXE и сохранения тренер напрямую не правит. Использует обычный ввод,
читает состояние процесса и кратко приостанавливает его основной поток,
чтобы определить текущий этап. Игра сама создаёт/подбирает предметы и
сохраняет мир. В обычном режиме файлы журналов тренер не создаёт.

Сборка: Visual Studio 2022, C++ x86, build.cmd. Наш код — лицензия 0BSD.
